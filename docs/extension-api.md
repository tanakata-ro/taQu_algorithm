# 拡張機能・外部ツール向けガイド

このリポジトリでは、taQu 本体サービスの非公開 API は公開しません。

拡張機能や外部ツールを作る場合は、`src/` の参考実装を組み込み、ルール文字列とプレイヤー状態を自分のツール側で扱う方式を推奨します。

## 公開された利用面

利用してよいもの:

- `src/index.js`
- `src/custom_rule.js`
- `src/custom_rule.js`（サービス本体と同期した参考実装）
- `src/rule_engine.js`（従来の読み込み方法を維持する互換入口）
- `src/types.d.ts`
- `docs/`
- `examples/`

依存しないでほしいもの:

- 非公開の socket イベント名
- 管理画面
- 認証処理
- DB 構造
- 不正対策の詳細
- 本番サーバー設定

## 基本パターン

1. ルール文字列を用意する
2. `src/index.js` が公開する `createRuleEngine` または `applyAction` を使う
3. ツール側のプレイヤー情報を `PlayerState` に変換する
4. ルールイベントを実行する
5. 戻り値をツール側のデータへ戻す

```js
const { applyAction } = require('taqu-algorithm');

const after = applyAction(ruleText, 'correct', {
  id: 'player-1',
  name: 'Alice',
  x: 0
});
```

## ブラウザ拡張でできること

例:

- 選択したルール文字列の構文チェック
- ルールの整形
- 定数やイベント一覧の表示
- 簡易シミュレーション
- エディタ補完

ブラウザ拡張は、taQu のログイン情報や非公開サーバー API を要求しない設計にしてください。

## 外部ツールでできること

例:

- ルールエディタ
- ルールテンプレート生成
- ローカルシミュレータ
- ルール lint
- カスタムルールの説明文生成

## 互換性について

この公開キットは、ルール記述と言語仕様の互換性を重視します。

taQu 本体サービスの UI、通信、管理機能、運営用機能は公開互換面ではありません。
